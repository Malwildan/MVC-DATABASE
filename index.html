Modul Ajar 1

Design Pattern MVC pada Laravel

Laravel menerapkan pola Model-View-Controller untuk memisahkan tanggung jawab aplikasi. Model menangani data dan logika bisnis, view menyajikan tampilan, dan controller menjadi penghubung di antara keduanya.

Apa itu MVC?

  • Model: mengelola data, logika bisnis, dan interaksi dengan database.
  • View: menyajikan informasi kepada pengguna dalam bentuk HTML atau Blade.
  • Controller: menerima input, memproses alur aplikasi, dan mengirim data ke view.

Langkah Implementasi

1. Membuat Model

php artisan make:model User

Model berada di app/Models/User.php dan biasanya berisi atribut fillable serta relasi.

2. Membuat Controller

php artisan make:controller UserController

Controller mengatur metode seperti index(), create(), dan store().

3. Membuat View

View berada di resources/views/users untuk menampilkan daftar dan form pengguna.

4. Menentukan Rute

use App\\Http\\Controllers\\UserController;
Route::resource('users', UserController::class);

Rute resource menyediakan endpoint CRUD secara lengkap.

Contoh Model
class User extends Model
{
    use HasFactory;

    protected $fillable = ['name', 'email', 'password'];
}
Contoh View
@foreach ($users as $user)
  <li>{{ $user->name }} ({{ $user->email }})</li>
@endforeach

Modul Ajar 2

Dasar Login dengan Laravel

Autentikasi pengguna dapat disiapkan dengan cepat menggunakan Laravel Breeze. Setelah instalasi, Anda dapat mengelola login, register, dan dashboard dengan alur yang jelas.

Urutan Dasar

  1. Instal Laravel melalui Composer.
  2. Atur koneksi database pada file .env.
  3. Pasang Laravel Breeze dan jalankan migrasi.
  4. Gunakan middleware auth untuk melindungi rute.

Contoh Konfigurasi

DB_CONNECTION=mysql
DB_HOST=127.0.0.1
DB_PORT=3306
DB_DATABASE=nama_database
DB_USERNAME=username_database
DB_PASSWORD=password_database
Contoh Form Login
<form method="POST" action="{{ route('login') }}">
  @csrf
  <input type="email" name="email" required autofocus>
  <input type="password" name="password" required>
  <button type="submit">Login</button>
</form>
Catatan: Laravel akan memverifikasi kredensial melalui controller autentikasi dan mengarahkan pengguna ke dashboard jika valid.

Kesimpulan

MVC dan login adalah fondasi penting dalam pengembangan aplikasi Laravel.

Dengan memahami pemisahan tanggung jawab, struktur direktori, dan autentikasi dasar, Anda memiliki dasar yang kuat untuk membangun aplikasi yang lebih besar dan lebih rapi.
